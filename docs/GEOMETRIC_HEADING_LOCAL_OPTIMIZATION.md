# 本地优化：实施与未解决问题

本轮在草稿 PR #6 上继续实施。main 基线仍为 `35b082b`，上一轮 PR 为
`cf7a63b`；共享底盘固定为 `8f986bda64d5b48af012d37cf924328e0b127468`。
没有更新 main，也没有启动新的物理 CI。以下全部是本地数值闭环。

## 已实施

- 每周期生成一个有效 yaw 路径：几何走向与独立终点 yaw 在圆周上插值，
  起步误差通过沿弧长衰减的偏置逐渐消除。直线大角度起步的偏置变化使用
  35% 的规划角速度预算，其余留给反馈和路线变化；完整可行性仍由速度包络、
  请求调理和轮组模型判断。这不是整条路线 yaw 导数的硬可行性证明。
- `ReferenceProfile`、seed、critic、名义轮姿、预转向/恢复和 retime 使用同一条
  有效路径。途中与终点不再是两个归一化不同的竞争目标；途中 yaw 的归一化
  尺度为 0.50 rad，终点为 0.10 rad，按同一接管权重改变单个误差的尺度。
  删除普通途中朝向的额外走廊惩罚；位置走廊和安全检查保留。
- 接近终点时，速度参考为最终转向预留时间；有序剩余距离与位置同时进入到点
  容差后停止平移修正，完成最终 yaw。朝向未完成时仍允许角速度控制。
- `GoalTolerance` 和 pose/stopped 判定由核心与适配层共用；ROS 使用实际
  `OrderedGoalChecker` 的配置。默认仍为位置 6 cm、yaw 0.05 rad、车体速度
  0.035、稳定时间 0.3 s；轮速 <=0.05 rad/s、零输出准备门槛及反馈健康检查保留。
- 到点停止后清除旧预转向意图，生成经过 slew、rollout 和全部 critic 验证的零请求。
  内部精确对齐不使用普通终点保持。有效参考及容差也随 retime 快照保存。
- 新增无需 ROS 的本地构建/单例入口、显式 32 例开关、参数与 CSV/图片记录，
  以及历史对照工具；不再默认每次全跑 32 例。详见 `LOCAL_TESTING.md`。

`EffectivePath` 表示已经准备好的内部运动参考，synthetic 分支/执行器契约测试
显式使用它；普通外部路径仍默认忽略中间 yaw，不提供 ROS 切回开关。
这次减少了重复目标和预转向反馈公式，但增加了可执行参考准备及测试设施，
不宣称总行数大幅下降。

## 同条件七例结果

seed 42、平移路径至少 12 m、上限 1 m/s、20 Hz 控制、100 Hz 执行，
独立 0.12 s 舵机，预测模型 0.10 s，每例最多 130 s。
同一批原始输入路径，main 使用输入中间 yaw，PR/当前实现忽略它。
因此 main 的侧移/倒车任务对车身转向要求更低；这些结果是实际效果比较，
不是完全相同朝向任务的性能排名。

passed 要求到点、停止、稳定、输出归零且全程 XY 偏差 <=10 cm。
这与严格 `closed_loop`、完整 Gazebo 质量验收是不同层次。

五个重点退化案例的当前完成时间仍长于 main。
不能把这些数值与上一轮 Gazebo 的 27/32 直接比较，也不能说全部问题已修好。

## 四组对照

| 组别 | 本地功能通过 | 说明 |
|---|---:|---|
| main | 7/7 | 原始中间 yaw、原始终点逻辑 |
| 只改几何 yaw | 1/7 | main 算法 + 测试调用方准备几何 yaw；原始末点 yaw 独立作为 goal |
| 只改终点接管 | 7/7 | 上轮 PR 算法；测试调用方保留原始中间 yaw |
| 两者都改（上轮 PR） | 5/7 | 上轮 PR 的正常策略 |

几何组前三个侧向/反向起步的峰值与上轮 PR 相同，支持“起步退化不能由终点
阈值解释”。只改终点组接近 main，说明没有几何车身转向要求时，此组数据上
终点更容易完成。几何组的终点停滞也暴露了旧终点算法假定路径 yaw 与 goal yaw
一致的问题。它使用调用方适配器，并非产品代码中两个开关的完全正交消融；
不能据此精确分摊每项实现的因果贡献。

逐例数据见 `docs/data/local_heading_comparison.csv` 和 `local_ablation_matrix.csv`。

## 仍然存在的较大问题

1. 严格 `closed_loop` 未恢复：plant=0、scenario=1 已到点，位置峰值 2.77 cm，
   但途中相对几何朝向 RMS 1.504 rad、峰值 1.567 rad。短路径中车身仍偏向保留
   初始朝向，软方向偏好与原有严格朝向门槛不相容。本轮没有修改其门槛或统计口径。
2. `stagnation` 比上轮出现更早的失败：case=0（12 m 直线 + 最终 180° yaw）
   在 t=16.1 s、剩余约 2.17 cm 时，位置峰值达到 10.54 cm，触发原有走廊检查。
   单独 `heading_sweep`、0.10 s 舵机复现：动作完成，但峰值 14.83 cm，最终误差
   4.59 cm、yaw 0.0231 rad，判定 path_deviation。需要进一步隔离大角度终点转向
   中的轮组切换/制动瞬态，不能只调整终点到点容差。
3. 当前 `reverse_diagonal` 与 `final_yaw` 虽完成，位置峰值比上轮本地结果差。
   main 仍更快、更准；当前实现尚不能宣称整体优化成功。
4. 本轮并发本地作业的 compute P99 不能作为受控性能比较或实时验收。
   当前七例记录约 51～57 ms，未证明满足现有 50 ms 门槛。没有放宽实时门槛。
5. 本地无 ROS/Gazebo，ROS 源探测返回 503；未验证本轮 ROS 编译、TF、里程计、
   生命周期、碰撞地图集成和 Gazebo 接触动力学。核心拒绝、执行器限幅和独立
   安装消费者已验证，但不能替代这些集成检查。

因为严格回归仍失败，本轮没有扩大为 32 例。按范围保留问题，不继续深入改造
轮组/大角度收尾；草稿 PR 不适合合入 main。
